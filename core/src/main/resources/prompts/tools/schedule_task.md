Create or manage this user's scheduled tasks. Use op=list to inspect existing plans before changing one; use its triggerId for pause, resume, delete, run_now, reschedule or edit. With op=create (default), schedule a future task only when the user asks you to do something later. For a fixed reminder, set reminder to the exact message and goal to its short description; this delivers without running a model. For work that needs app or web operations, omit reminder. Use at for a one-time or fixed-interval start; use repeatAt for a single daily local clock time, or repeatTimes for several times in one day (e.g. 08:00, 12:30, 20:00) that share one plan, with repeatZone and optional weekdays, so daylight-saving changes do not shift the clock time. op=edit changes only the fields you pass: goal, condition, reminder, at, repeatTimes, repeatZone, weekdays, intervalMinutes or whenIdle; pass an empty condition or reminder string to clear it, repeatTimes as [] to drop the clock schedule, and intervalMinutes 0 to drop an interval. A task can have a reminder or a condition, not both. A condition is checked first with read only web and sandbox tools; the task runs only if the condition becomes met. Set whenIdle when the user wants the task to wait for an idle period after that time. Do not claim that a future task is arranged until this tool succeeds.
